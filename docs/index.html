使用 skills.sh CLI。-g 全局安装，-y 跳过确认。

▶ 安装全部 40 个技能（含第三方及付费依赖）

npx skills add maoyao0607/ai-skills --skill '*' -g -y

◆ 按 skill 安装

★ 按分组安装

  • 先读 SKILL.md：按工作流与 references 执行，勿跳过质量门禁。
  • Harness 优先：ai-coder / code-review / diagnosing-bugs 遵循目标仓库 AGENTS.md。
  • 需求抽取先声明主体；报工只基于证据，勿编造。
  • 存储扫描只读；清理服务可删除文件。原技能注明 Windows 未经真实环境验证。
  • NEXUS 会向第三方发送输入并涉及付费；agent-git-oracle 也声明外部工具及付费依赖。安装不代表授权调用。
