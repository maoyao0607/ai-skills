# 质保报工句式示例

序号用纯文本 `1、` `2、`；每条默认 ≤30 字（说不清可略放宽）。  
禁止 Markdown `1.`、禁止「已提交」、禁止罗列相关文件。

## 单次报障

**输入线索**：计划模块统计失败；脚本版本旧；升到 V2.3；验证 OK

**输出**：

```text
**项目名称**：XX 集团 ERP 系统建设项目

**具体工作内容**：
1、计划模块统计报错，升脚本至 V2.3 后验证通过。
```

## 缺陷修复 + 现场确认

**输入线索**：入库单打印空白；模板字段映射缺；补映射；复打通过

**输出**：

```text
**项目名称**：【待补：项目标准名称】

**具体工作内容**：
1、入库单打印空白，补字段映射后现场复打通过。
```

## 当前周合并（模式 B · Git + Agent 对话）

**输入线索**（本周一至今）：审批流超时改网关；报表乱码改 UTF-8；操作说明交付

**输出**：

```text
**项目名称**：XX 集团 ERP 系统建设项目

**具体工作内容**：
1、采购审批超时，回调改内网网关后压测通过。
2、报表导出乱码，改 UTF-8 后复测通过。
3、操作说明已交付现场使用。
```

## 用户声明项目名后应写入记忆

用户：「当前项目是 华润医药 MES 升级项目」

Agent：报工使用该名称，并写入 `.cursor/rules/hs-warranty-project.mdc`，下次直接读取。
